# Хьюманайзер для Codex

Скилл для подготовки и редактуры текстов к публикации. Сохраняет смысл, факты, цифры и голос автора. Внутри 15 правил для русского текста и [справочник признаков из Википедии](humanizer/references/wikipedia-signs.md).

## Установка в Codex

1. Отправьте в чат Codex эту команду.

   ```text
   $skill-installer Установи скилл https://github.com/nikpanaev/humanizer/tree/v1.0.0/humanizer
   ```

2. После установки вызовите скилл командой `$humanizer Перепиши этот пост для публикации` и добавьте текст. Codex также может выбрать скилл автоматически при работе с текстами для публикации. Если скилл не появился, перезапустите Codex.
